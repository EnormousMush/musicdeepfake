# Progress report — 家族指纹证实 + 生成器版图扩到 14 家 + 流匹配线开工 (2026-07-31)

接上一份(消融三连 + 跨生成器矩阵)。这五天回答了上份报告留下的"ACE-Step 决定性一刀",
并沿着"找共性,或证明没有共性"的纲领把生成器版图从 6 家扩到 14 家。
数字均为 test EER,MERT/MuQ 逐层 linear probe,共同规格(10s/16kHz/mono/LUFS-23),复旦 GPU。

## 一、同 prompt 对照协议 + 家族覆盖假设证实(Batch 6)

用自有 Suno 数据集的 10,750 条冻结 prompt,给新生成器**逐条出同一道题**(内容变量构造上锁死),
各生成 1000 首 instrumental 并入评测池。首批:ACE-Step 1.5(LM+流匹配渲染,Suno 疑似同架构族)
与 DiffRhythm 2(Block Flow Matching,异族)。

| 生成器(vs Suno 探针) | MuQ @L* | MERT @L* | 备注 |
| --- | --- | --- | --- |
| ACE-Step | **3.79%** | 12.78% | 未见过、跨公司,近域内 |
| DiffRhythm 2 | 37.2% | 28.2% | **同 prompt**、同现代 |
| (域内 Suno) | 0.22% | 1.89% | |

**同 prompt 内控是关键设计**:两者拿的是逐条相同的 prompt,内容持平下 10 倍差距
→ 指纹按**架构族**共享,"Suno 专属"实为**家族指纹**。
leave-one-generator-out(LOGO)侧:给训练池补上现代族代表后,留出 Suno 从 44.9% → **29.3%**。

## 三、Batch 7 主结果:铁三角 + 族由架构定义 + MuQ 通杀

**A. 家族铁三角。** LeVo 入列后(vs Suno 探针):

| 生成器 | MuQ @L* | 家族 |
| --- | --- | --- |
| ACE-Step | 4.21% | LM+FM ✅ |
| **LeVo** | **6.21%** | LM+FM ✅ |
| DiffRhythm 1 | 28.2% | 全曲 CFM ❌ |
| DiffRhythm 2 | 35.6% | Block FM ❌ |

三家独立实验室(Suno / ACE-Step / 腾讯)的同族模型全部近域内——
"ACE-Step 恰好像 Suno"的单证人质疑被排除。

**B. 族由架构定义,不由数据谱系定义。** DR1 vs DR2:同实验室、同数据、不同架构 → 都远
(28%/36%)。全池唯一能做该对照的一对,答案干净。

**C. LOGO 扩到 10 员 + MuQ 惊喜。** MERT 侧留出 Suno 28.2%;**MuQ 侧 17.8%**——
且 MuQ+多样池几乎通杀(其余留出者 1.2–4.7%),唯二顽固:**DiffRhythm 血统**(dr2 32%、dr1 20%)。
新表述:**音乐 SSL + 池多样性可弥合大部分族;残余 = 直接流匹配渲染类 + 商用未知族。**

## 四、SONICS devocal 附表(对称处理协议)

SONICS 全员带人声,与我们 instrumental 体系冲突 → demucs 伴奏分离,且**对照的 fma-test 与
suno-test 同参数过同一把刀**(处理痕迹必须两类共享,否则刀口本身成捷径——同编码历史检查逻辑)。

- **demucs 汇率几乎免费**:域内 MuQ 0.22→0.33%、MERT 1.9→2.4% → 附表可信;
- **Suno 版本漂移巨大且断代**:v2/v3/v3.5 在 MERT 下 22–26%(域内 2.4%),三版本间差异小
  ——探针只认当代 Suno,版本指纹是断代跳变不是渐进漂移(未见有人发表过此测量);
- **Udio ≈ 掷硬币(43–46%)**:跨族结论首次拿到商用侧证据;
- 彩蛋:MuQ 的 val 选层在该域反向(L0 五行 51–64%,L3 才正常)——选层在域偏移下的脆性。

## 五、流匹配线开工(你的原始思路,现在动机最锋利)

判别式路线的残余(17.8% / DR 血统 / Udio)正是"不学假货指纹、建流形量偏离"路线的靶子。
三阶推进,每阶允许发散:

1. **单类基线(脚本已就绪,Batch 8 首跑)**:只用 fma-train 特征建真实流形,
   马氏距离(Lee 2018)+ kNN(Sun 2022)双打分器,与判别式矩阵同测试床对表。
   预注册假设:kNN 胜 ⇒ 真实音乐流形多中心(触发 genre 资格考试:无监督聚类先验证
   团-标签对应,过了才允许 per-genre 质心);
2. **重建探针**:EnCodec 重建误差;
3. **流匹配本体**:ACE-Step / InspireMusic 的流模型算"离生成流形距离"——
   与①互为镜像(真实流形一岸、生成流形一岸),两岸一致则故事极硬。
文献侧已入库:Zhang 2021 / Kim 2024 / QAMO 2025(单类谱系)+ Lee 2018 / Sun 2022(打分器本体)。
