# Progress report — 消融三连 + 跨生成器矩阵 (2026-07-26)

接上一份(round-1 + 混淆控制计划)。这两周把"年代混淆的便宜载体"全部实验清空,并用
FakeMusicCaps 跑出了我们自己的跨生成器 EER 矩阵。数字均为 test EER,MERT 逐层 linear probe,
复旦 GPU。

## 一、消融三连:便宜混淆载体全部排除

在 round-1 数据(3000 Suno + 3000 FMA instrumental)上,预先写死判读标准再跑:

| 实验 | 操作 | 结果 | 结论 |
| --- | --- | --- | --- |
| 打乱标签 | train 标签 shuffle 后重训 | 全层 49–54% | 无泄漏,结果可信 |
| 带宽匹配 | 两类同低通 8kHz,重抽重探针 | 0.11–0.89% → 0.22–1.11%,不动 | >8kHz 高频不是驱动 |
| 编码历史 | 两类同过 mp3 128k 往返 | 完全不动(最佳层 0.11%) | 压缩痕迹差被排除 |
| 频谱包络匹配 | 每首 EQ 到同一全局平均谱形(纹理保留,烟测包络差 1.29→0.04) | 不动(最佳层 0.33%) | **亮度/倾斜彻底排除** |

**累计排除清单:响度、genre、泄漏、>8kHz、编码历史、全频段亮度/倾斜。**
剩下的信号刻画:**宽带时频纹理,扛低通、扛 mp3 重压、扛整体音色拉平。**
剩两个假设:①深层制作纹理(动态/母带/噪底)= 年代混淆深水区;②真·生成指纹。

## 二、跨生成器矩阵(FakeMusicCaps,5 个开源 TTM)

为裁决①②,下载 FakeMusicCaps(27,605 clips,5 生成器),与我们的数据**对齐到共同规格**
(10s/16kHz/mono/LUFS-23,同一处理链——先堵 TISMIR 指出的采样率/码率管线捷径)。
Suno-vs-FMA 训练,域内基线新规格下 L*=7 test **1.89%**;每生成器 1000 首 vs FMA-test:

| 生成器 | EER @L* | 逐层最优 |
| --- | --- | --- |
| stable_audio_open | **31.5%** | 27.0% |
| MusicGen_medium | **36.2%** | 32.4% |
| mustango | 49.1% | 46.8% |
| musicldm | 53.0% | 48.2% |
| audioldm2 | **57.3%(劣于瞎猜)** | 53.4% |

**读法:**
1. **全线崩塌**——复现了 MusicDET 报告的领域惨案(其 48.7%):判别式探针没学到通用 AI 痕迹;
2. **崩塌有序**:迁移率按生成器**制作现代度**排序;audioldm2 的糊/窄带输出被判到比真 FMA 更"人类"
   的一侧(EER 反向)→ 决策边界里确有一根**"现代干净 ↔ 老 lo-fi"制作轴**(假设①的正面实锤),
   同时残留 Suno 专属成分(否则 stable_audio_open 应接近域内而非 31%);
3. caveat:FakeMusicCaps 内容 = MusicCaps caption(含类人声)≠ 我们的 instrumental,会抬高跨域
   EER,但解释不了 audioldm2 的反向——制作轴才解释得了。

**结论:探针学到的 = 制作现代度轴 + Suno 专属成分的混合;都不是通用 AI 指纹。**

## 三、下一步(按信息量排序)

1. **ACE-Step 成为决定性一刀**:现代+干净+流匹配+可控 instrumental prompt(同时消掉 content
   shift)。迁移好 → 制作轴主导,主线转向重建/单类去混淆;也 ~50% → Suno 指纹主导,
   "Suno 专属鲁棒指纹"本身可成论文重心。
2. **leave-one-generator-out 混训**(FakeMusicCaps 特征已缓存,零成本):4 训 1 测,
   量判别式路线的通用化上限。
3. **单类/重建路线的动机升级**:MusicDET(只学真实分布,零样本跨生成器 4.51%)与你的
   flow-matching 直觉同构;现在我们有了**自己的数据**证明判别式的宿命,这条探索线的优先级上调。

## 附:方法论沉淀
所有实验判读标准**预先写死**(防事后合理化);两类音频永远走**同一条处理链**(防管线自造混淆);
所有特征缓存、实验可秒级复跑。这套"混淆电池"流程本身计划写成论文的方法论章节。
